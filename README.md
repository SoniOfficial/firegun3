# FIRE GUN v1.1 — бозии ҷангии 2D (Android, оффлайн)

**Номи бастаи Android:** `tj.soni.firegun` · **Забон:** Kotlin · **Минимум:** Android 8.0 (SDK 26) · **Ҳолат:** 100% оффлайн, ландшафт

## 1. Сохтани репозитории GitHub
1. Ба https://github.com даро ва ворид шав (агар аккаунт надорӣ, сабти ном кун).
2. Дар боло тарафи рост тугмаи **+** → **New repository** -ро зер кун.
3. Дар **Repository name** `FIRE-GUN` нависед, **Public** ё **Private** интихоб кун.
4. **Create repository** -ро зер кун.

## 2. Боркунии файлҳо
1. ZIP-ро кушо (extract кун). Дохили он папкаи `FIRE_GUN` ҳаст.
2. Дар саҳифаи репозитории нав **uploading an existing file** -ро зер кун.
3. **Ҳамаи** файлу папкаҳои дохили `FIRE_GUN`-ро (на худи папкаро) кашида андоз. Папкаи `.github` ҳатман бояд бошад.
   - Агар `.github` дар телефон/компютер намоён нест, "Show hidden files"-ро фаъол кун.
4. **Commit changes** -ро зер кун.

Бо Termux (git) низ мешавад:
```
cd FIRE_GUN
git init && git add -A && git commit -m "FIRE GUN v1.0"
git branch -M main
git remote add origin https://github.com/НОМИ_ШУМО/FIRE-GUN.git
git push -u origin main
```

## 3. Иҷрои GitHub Actions
- Баъди боркунӣ workflow худаш оғоз мешавад (push).
- Дастӣ: **Actions** → **Android CI** → **Run workflow**.
- Таҳлил 5–10 дақиқа мегирад: аввал тестҳои unit, баъд APK сохта мешавад.

## 4. Боргирии APK
1. **Actions** → охирин иҷрои сабз (✓) -ро кушо.
2. Поёнтар дар қисми **Artifacts** файли **FIRE-GUN-APK** -ро зер кун (ZIP мешавад).
3. ZIP-ро кушо — дохили он `app-debug.apk`.

## 5. Насб дар Android
1. `app-debug.apk`-ро ба телефон гузар.
2. Онро кушо; агар хоҳад, "Install unknown apps" (насб аз манбаъҳои номаълум)-ро иҷозат деҳ.
3. **Install** → **Open**.

## 6. Навсозии бозӣ дар оянда
1. Файлҳоро тағйир деҳ (масалан `data/Weapons.kt` барои силоҳи нав, `data/Missions.kt` барои миссияи нав).
2. Файлҳои тағйирёфтаро дар GitHub ҷойгузин кун (ё `git commit` + `git push`).
3. Actions дубора APK месозад.
4. Барои навсозии версия `versionCode` ва `versionName`-ро дар `app/build.gradle.kts` зиёд кун.

## Режими KINGDOM (Open World) — НАВ в v1.1
**PLAY → KINGDOM → BUILD.** Харитаи калон (5200×3800): 4 салтанат (шумо = кабуд, 3 душман: сурх, бунафш, норанҷӣ), кӯлҳо, ҷангалҳо, роҳҳо, 5 лагери роҳзанон ва рӯз/шаб бо равшании машъал.
- **Шумо подшоҳ мешавед:** аз рутбаи LORD оғоз мекунед. Қалъаро `UPGRADE` кунед → BARON → DUKE → **KING**. Ҳар сатҳ қалъаро қавитар ва артишро зӯртар мекунад.
- **Хона бисозед (тугмаи BUILD):** House (+5 ҷойи артиш), Gold Mine (+тилло), Barracks (сарбоз/камонвар), Stable (рыцарь), Tower (тир мезанад), Wall (девор). Бо ҷойстик ҷой интихоб кунед, пешакӣ сабз/сурх нишон медиҳад, баъд **PLACE**.
- **Артиш (тугмаи ARMY):** Soldier 50, Archer 70, Knight 150 тилло. Ҳадди артиш = 6 + 5×House + 4×сатҳи қалъа.
- **Фармон (тугмаи ORDER):** FOLLOW (аз паси шумо), HOLD (истодан), ATTACK (ҳамла ба салтанати интихобшуда), DEFEND (ҳимояи қалъа). Дар ATTACK тугмаи TARGET ё зеркунии қалъа дар **minimap** (боло-рост) ҳадафро иваз мекунад.
- **Ҷанг:** худи шумо низ бо силоҳҳои худ (аз дӯкон) меҷангед; дар назди қалъа ҷон ва патрон барқарор мешавад. Агар афтед, баъди 6 сония дар қалъа зинда мешавед.
- **Душманон ҳам рушд мекунанд:** қалъа месозанд, артиш тайёр мекунанд ва ҳар ~1.5 дақиқа ба шумо ё ба якдигар ҳамла мекунанд («ARMY ATTACKS YOUR KINGDOM!»). Роҳзанон лагерҳоро посбонӣ мекунанд; лагерро тоза кунед → тилло.
- **Ғалаба:** қалъаи ҳар 3 душманро вайрон кунед → **YOU ARE THE KING!** (+1500 танга ва тоҷ). Агар қалъаи шумо вайрон шавад, мағлуб мешавед. Тангаҳо ба дӯкони асосӣ меоянд.

## Сохтори лоиҳа
```
app/src/main/java/tj/soni/firegun/
  MainActivity.kt        — Activity, back-тугма, lifecycle
  core/                  — Game, GameView (ҳалқаи бозӣ, delta-time), MathX
  data/                  — Weapons, Missions, SaveManager (захираи маҳаллӣ)
  game/                  — World (мантиқ, AI, тир, гранат), Entities
  render/                — Sprites, Terrain, WorldRenderer, MenuArt (графикаи барномавӣ)
  kingdom/               — KingdomWorld (open world, AI салтанатҳо), KRenderer, KSprites
  ui/                    — Ui (тугма, бар, нишона) ва ҳамаи экранҳо (KingdomScreen ҳам)
  audio/SoundManager.kt  — SoundPool
app/src/main/res/raw/    — садоҳои WAV (оффлайн)
```
Барои илова: душмани нав → `EType` + `Sprites`; силоҳи нав → `Weapons.all`; миссия → `Missions.all`; харита → `World.generateMap`/`Terrain`.

## Идора
- Чап: ҷойстик (ангушт ҳар ҷои нимаи чапи экран).
- **FIRE** — тир (ба наздиктарин душман худкор нигаронида мешавад; дар Settings хомӯш мекунед).
- Гранат, **R** (reload), тугмаи тағйири силоҳ, **II** (пауза).

## Хусусиятҳо
Режими Mission (10 миссия) ва Survival (мавҷҳо, босс дар ҳар мавҷи 5-ум); 5 намуди душман (Soldier, Scout, Heavy, Sniper, Boss); 5 силоҳ + гранат; пикапҳо (ҷон, зиреҳ, патрон, танга); дӯкони силоҳ, такмилҳо, ашё ва сандуқ; HUD, пауза, Game Over (бо REVIVE), Mission Completed (ситора); ҷойстик; садоҳо; захира дар SharedPreferences; ларзиши экран, таркиш, дуд; ҳамаи графика бо Canvas сохта шудааст.

## Маҳдудиятҳо (рости гап)
- Ин лоиҳа дар муҳити сохтан (бе Android SDK/Gradle/интернет) **наомадааст сохта шавад ва APK санҷида нашудааст**. Файли `gradle-wrapper.jar` низ илова нашудааст; workflow Gradle 8.7-ро худаш насб мекунад ва `gradlew` лозим нест.
- Агар сохтан хато диҳад, матни хаторо аз Actions log нусхабардорӣ карда фиристед — ислоҳ мекунем.
- Садоҳо синтезшуда (содда) мебошанд; графика барномавӣ аст ва ба расмҳои намунавӣ наздик аст, вале айнан як хел нест.
- Open World: захираи байни сессияҳо нест (ҳар бор нав оғоз мешавад; фақат танга, тоҷ ва ҳисоб нигоҳ дошта мешаванд). Мультиплеер ва мусиқии замина нест.
